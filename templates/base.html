EduGenie Setup & API Configuration

EduGenie connects securely to Google Gemini using your GEMINI_API_KEY set in the project .env file. Your key stays protected on the server and is never sent to the browser.

How to configure your API key:

  1. Get a free key from Google AI Studio.
  2. Open the .env file in your EduGenie project root folder.
  3. Paste your key: 
    GEMINI_API_KEY=AIzaSy...YourKeyHere...
GEMINI_MODEL=gemini-3.5-flash-lite
  4. Save the file. EduGenie automatically picks up the updated key!
